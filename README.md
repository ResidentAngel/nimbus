# ☁ nimbus

Терминальный аудиоплеер для SoundCloud на Go: ищет треки, открывает ссылки и плейлисты,
играет их подряд — без рекламы, браузера и лишних окон. Один бинарник, без cgo на Windows.

```

│   lofi hip hop                                                               │
╰──────────────────────────────────────────────────────────────────────────────╯
```

## Возможности

- поиск треков прямо из терминала;
- ссылки на трек, плейлист/альбом или профиль исполнителя;
- очередь: после трека автоматически играет следующий, недоступные пропускаются;
- пауза, громкость, переключение треков, прогресс-бар;
- воспроизведение вперемешку (`r`);
- мультимедийные клавиши ⏯ ⏭ ⏮ (Fn + F-клавиши на ноутбуке) — даже когда терминал свёрнут (Windows);
- перемотка стрелками (±10 с, с Shift — ±30 с);
- история прослушивания: последние 200 треков, сохраняется между запусками;
- лайки: хранятся локально, переносятся на другое устройство одним JSON-файлом;
- потоковое воспроизведение с фоновой подкачкой — звук не заикается на медленной сети;
- `client_id` для API определяется автоматически и кэшируется;
- уведомление о новой версии и обновление одной командой `nimbus update`.

## Установка

**Готовый файл (Go не нужен).** Скачайте сборку для своей системы со страницы
[Releases](https://github.com/ResidentAngel/nimbus/releases/latest):
`nimbus_windows_amd64.exe`, `nimbus_darwin_arm64` (Mac на Apple Silicon), `nimbus_linux_amd64` и т.д.
Переименуйте в `nimbus.exe` (или `nimbus`) и положите в папку из `PATH`.

**Через Go 1.24+:**

```bash
go install github.com/ResidentAngel/nimbus@latest
```

Или из исходников:

```bash
git clone https://github.com/ResidentAngel/nimbus
cd nimbus
go build -o nimbus .
```

На Linux для звука нужны заголовки ALSA (`sudo apt install libasound2-dev`) и cgo.
На Windows и macOS ничего дополнительно ставить не надо.

**Рекомендуется ffmpeg.** SoundCloud постепенно отключает MP3-потоки, и многие треки
доступны только в AAC/Opus — их nimbus перекодирует через ffmpeg из `PATH`:

```bash
winget install Gyan.FFmpeg      # Windows
brew install ffmpeg             # macOS
sudo apt install ffmpeg         # Linux
```

## Использование

```bash
nimbus                                   # открыть плеер
nimbus lofi hip hop                      # сразу искать
nimbus https://soundcloud.com/user/sets/playlist
```

| Клавиша           | Действие                          |
|-------------------|-----------------------------------|
| `/` или `s`       | поиск (Enter — найти, Esc — назад) |
| `↑` `↓` / `j` `k` | выбор трека                       |
| `Enter`           | играть выбранный                  |
| `Пробел` / `p`    | пауза                             |
| `←` / `→`         | перемотка на 10 с                 |
| `Shift`+`←`/`→`   | перемотка на 30 с                 |
| `0`               | в начало трека                    |
| `r`               | вперемешку: вкл/выкл              |
| `n`               | следующий трек                    |
| `b`               | предыдущий трек                   |
| `f`               | лайк выбранному треку / снять     |
| `F`               | лайк треку, который сейчас играет |
| `Tab` / `Shift+Tab` | вкладки: Поиск → История → Лайки |
| `h`               | история / назад к поиску          |
| `+` / `-`         | громкость                         |
| `c`               | показать ссылку на текущий трек   |
| `?`               | подсказка                         |
| `q`               | выход                             |

### Мультимедийные клавиши

На Windows nimbus слушает системные кнопки ⏯ ⏭ ⏮ ⏹ — на ноутбуках это обычно Fn + F-клавиши.
Они работают, даже если окно терминала свёрнуто:

| Кнопка | Действие |
|--------|----------|
| ⏯      | пауза / продолжить (или запустить выбранный трек) |
| ⏭      | следующий трек |
| ⏮      | в начало трека, если прошло больше 3 с, иначе предыдущий |
| ⏹      | пауза |

Пока nimbus запущен, эти кнопки управляют им, а не другими плеерами.
Отключить: `NIMBUS_NO_MEDIA_KEYS=1`. На macOS и Linux пока не поддерживается.

**F6 / F7 / F8 (Fn + F6/F7/F8 на ноутбуке).** Клавиша Fn обрабатывается самим ноутбуком
и до программ не доходит — они видят только то, что ноутбук отправил в итоге. Если у вас
Fn + F7 отправляет обычную F7, включите режим `-fkeys`:

| Клавиши | Действие |
|---------|----------|
| F6 (Fn+F6) | предыдущий трек |
| F7 (Fn+F7) | пауза / продолжить |
| F8 (Fn+F8) | следующий трек |

```bash
nimbus -fkeys                    # один раз
setx NIMBUS_FKEYS 1              # включить навсегда (Windows, в новом терминале)
```

В этом режиме F6/F7/F8 заняты во всей системе, пока nimbus открыт — например,
в IDE не будут работать F7/F8 отладчика. Внутри окна nimbus F6/F7/F8 работают всегда.

Горячие клавиши работают и на русской раскладке (`а` = `f`, `т` = `n`, `к` = `r`…).

## Обновление

При запуске nimbus в фоне проверяет, вышла ли новая версия, и пишет об этом в шапке.
Обновиться:

```bash
nimbus update
```

Команда скачает сборку для вашей системы с GitHub Releases, проверит SHA-256
по `checksums.txt` и заменит текущий файл. Отключить проверку при запуске:
переменная окружения `NIMBUS_NO_UPDATE_CHECK=1`.

### Выпуск новой версии (для автора)

```bash
git tag v1.1.0
git push origin v1.1.0
```

GitHub Actions ([release.yml](.github/workflows/release.yml)) соберёт файлы для
Windows, macOS и Linux, посчитает контрольные суммы и опубликует релиз.

## Лайки

Лайки — локальные, без входа в аккаунт SoundCloud. Трек с лайком отмечен ♥,
все лайки собраны на вкладке «Лайки». Перенос на другое устройство:

```bash
nimbus likes export likes.json      # на старом устройстве
nimbus likes import likes.json      # на новом: добавит недостающие, дубли пропустит
nimbus likes import https://soundcloud.com/ник/likes   # забрать лайки своего профиля SoundCloud
nimbus likes list                   # посмотреть список
nimbus likes remove 3 7             # снять лайки по номерам из list (или по ссылке на трек)
nimbus likes path                   # где лежит рабочий файл
```

Импорт по ссылке берёт **публичные** лайки любого профиля (вход в аккаунт не нужен,
скрытые лайки недоступны). Подойдёт и короткая ссылка `on.soundcloud.com/…` из приложения.
Если вставить ссылку `soundcloud.com/ник/likes` в строку поиска плеера, лайки профиля
откроются списком — их можно сразу слушать.

Файл экспорта — обычный JSON (`{"app":"nimbus","version":1,"likes":[...]}`),
его можно хранить в облаке или в git. Токены и временные ссылки на потоки
в него не попадают.

## Где хранятся данные

История и лайки лежат в `%AppData%\nimbus\` (Windows),
`~/Library/Application Support/nimbus/` (macOS) или `~/.config/nimbus/` (Linux):
`history.json` и `likes.json`.

Свой `client_id` можно передать флагом `-client-id` или переменной `SC_CLIENT_ID`.
Если трек не играет, запустите `nimbus -debug nimbus.log` — в лог попадут доступные форматы и ошибки.

## Как это устроено

```
main.go                  запуск
internal/soundcloud      клиент api-v2: поиск, resolve, выбор потока, HLS, ffmpeg
internal/player          воспроизведение MP3 через gopxl/beep + oto
internal/history         история прослушивания (JSON)
internal/likes           лайки, экспорт и импорт (JSON)
internal/update          проверка релизов и самообновление
internal/mediakeys       мультимедийные клавиши (Windows: RegisterHotKey)
internal/ui              интерфейс на Bubble Tea + Lip Gloss
```

1. Поиск и ссылки идут в `api-v2.soundcloud.com`.
2. Для трека выбирается лучший поддерживаемый поток: progressive MP3 → HLS MP3 → HLS AAC/Opus через ffmpeg.
3. Данные подкачиваются в фоне в буфер (~8 МБ), декодер читает уже из памяти.

Реклама не проигрывается просто потому, что nimbus — отдельный клиент и запрашивает только аудио.

## Ограничения

- Треки только для подписчиков **SoundCloud Go+** защищены DRM — nimbus их пропускает
  и не пытается обойти защиту. Если доступен лишь 30-секундный фрагмент, плеер об этом сообщит.
- Перемотка переоткрывает поток с нужного места, поэтому занимает около секунды.
- Неофициальный клиент: SoundCloud может изменить API в любой момент.
